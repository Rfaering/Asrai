# Product developer tests

Add focused `*.test.mjs` tests here as product capabilities are implemented. `npm test` runs these together with evaluator self-tests; browser/oracle integration tests remain separate under `reference/tests/`.

There is deliberately no diagram implementation in the founding assignment. Tests in `evaluation/tests/` and `reference/tests/` use transport/fixture mocks only to verify the harness and must never be reported as product compatibility evidence.
