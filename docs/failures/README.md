# Corrective iteration record

For a failed autonomous attempt, create a short file with:

```text
Capability / attempt / date:
Candidate and acceptance digests:
Command and report path:
Failure category:
Smallest input:
Expected / actual:
Cause and correction:
Retest result:
Attempts / elapsed time / human interventions:
Unresolved question or escalation:
```

Keep the report authoritative. Do not duplicate full logs or change acceptance to hide the failure. After three attempts without improvement, record the blockage and switch to independent ready work if available.
